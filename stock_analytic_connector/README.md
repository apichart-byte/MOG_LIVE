# Stock Analytic Connector

This module connects Sales/Purchase analytic distribution to Stock Moves.

## Features
- Adds `analytic_distribution` field to `stock.move`.
- Automatically populates the field from Sales Order Lines or Purchase Order Lines.
- Displays the analytic distribution in Stock Picking and Stock Move forms.

## Dependencies
- `stock`
- `sale_stock`
- `purchase_stock`
- `analytic`
